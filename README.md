Creates structured JSON-LD menu schemas for SEO, supports dynamic pricing by time-of-day and day-of-week, tracks 86d items in real time, and generates weekly food cost reports. Works with any theme using a shortcode and Gutenberg block.

== Description ==

WordPress plugin for restaurant owners managing digital menus and inventory in one dashboard. Creates structured JSON-LD menu schemas for SEO, supports dynamic pricing by time-of-day and day-of-week, tracks 86d items in real time, and generates weekly food cost reports. Features allergen flagging, dietary preference filtering, and QR code generation for table menus. Integrates with Square and Toast POS systems via webhook for real-time inventory sync. Works with any theme using a shortcode and Gutenberg block.

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Restaurant Menu and Inventory Manager WordPress Plugin
